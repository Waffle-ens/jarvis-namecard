# JARVIS 모바일 명함

명함 원본의 아이보리·골드·네이비 색상을 활용한 반응형 정적 페이지입니다.

공개 주소: https://waffle-ens.github.io/jarvis-namecard/

## 구성

- 이름, 직함, 업무 분야 안내
- 전화·이메일 바로 연결
- 연락처 파일(vCard) 다운로드
- 공유 이미지 미리보기, 기기 기본 공유 메뉴와 링크 복사
- 카카오 JavaScript 키 연결 후 이미지와 ‘명함 보기’ 버튼이 있는 카카오톡 카드 메시지
- 데스크톱 원본 명함 표시, 모바일 원본 명함 펼쳐 보기
- 링크 미리보기용 제목·설명·가로형 명함 이미지 메타데이터

카카오톡 카드 메시지 설정은 [KAKAO_SETUP.md](./KAKAO_SETUP.md)를 참고합니다. **현재 `site-config.js`의 JavaScript 키는 비어 있으며, 연결 전에는 카카오톡 전용 버튼을 숨깁니다.** 유효한 키를 입력한 뒤 허용 도메인을 등록하면 노란색 카카오톡 버튼이 표시됩니다. 카카오 SDK는 설정이 있을 때 공유 창을 처음 열면 불러옵니다.

‘다른 앱으로 공유’는 기기의 일반 공유 메뉴이며 카카오톡 카드 메시지와 다릅니다. 표시되는 앱 목록은 기기와 브라우저에 따라 달라집니다. vCard 다운로드 후 주소록에 추가하는 방식도 운영체제에 따라 다르며, 카카오톡 내부 브라우저에서 다운로드가 제한되면 기본 브라우저로 열어 저장합니다.

## 로컬 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

미리보기: http://127.0.0.1:4173/

```sh
npm run check
npm run build
```

`dist/`에는 배포용 HTML, CSS, JavaScript, 공유 설정, 명함 이미지, 연락처 파일만 복사됩니다. 이름과 연락처는 `index.html` 및 `yoonbo-sim.vcf`에서 수정합니다. 카카오 카드의 이름·설명은 `app.js`의 메시지 구성에도 반영합니다.

## GitHub Pages

현재 공개 저장소의 `main` 브랜치 루트(`/`)를 배포 원본으로 사용합니다. 변경 사항을 `main`에 푸시하면 GitHub Pages가 배포합니다. `.nojekyll`로 원본 정적 파일을 그대로 제공합니다. 별도 서버, 데이터베이스, 유료 서비스는 필요하지 않습니다.

현재 사이트는 개인 소개와 연락처 안내만 제공합니다. 온라인 판매, 결제, 유료 SaaS 기능을 추가하려면 GitHub Pages의 이용 범위를 다시 확인하고 적절한 호스팅으로 이전합니다.

## 다른 호스팅으로 옮기기

일반적인 정적 호스팅에는 `dist/` 폴더를 배포합니다. 환경 변수 `SITE_URL`에 새 공개 주소를 지정하고 빌드하면 canonical, `og:url`, `og:image`가 갱신됩니다. 다른 주소로 루트 파일을 직접 배포할 때는 `index.html`의 해당 주소 세 곳도 함께 변경합니다. 카카오톡 공유를 사용한다면 새 도메인도 카카오 앱의 두 도메인 설정에 등록합니다.

Vercel 설정(`vercel.json`)도 포함되어 있습니다. Vercel Hobby는 비상업적 이용으로 제한되므로 업무용 사이트에는 적합한 유료 요금제가 필요합니다.

카카오톡 링크 미리보기는 캐시될 수 있습니다. 제목이나 설명을 변경한 뒤 갱신되지 않으면 [카카오 URL 메타정보 초기화 도구](https://developers.kakao.com/tool/clear/og)를 사용합니다.

## 주요 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 내용, 검색·공유 메타데이터 |
| `styles.css` | 모바일·데스크톱 스타일 |
| `app.js` | 카카오톡 카드 공유, 기기 공유, 링크 복사와 오류 안내 |
| `site-config.js` | 카카오 JavaScript 공개용 키 설정 |
| `namecard.png` | 사용자 제공 원본 명함 |
| `share-card.png` | 가로형 공유 이미지(1774 × 887px) |
| `yoonbo-sim.vcf` | 주소록에 저장할 연락처 |
| `scripts/serve.mjs` | 의존성 없는 로컬 미리보기 서버 |
| `scripts/build.mjs` | 정적 배포 폴더 생성 |
